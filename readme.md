🌿 Nova-Greenden
Nova-Greenden is a modern, responsive e-commerce web application designed for a plant and flower shop. Built with HTML5 and Tailwind CSS, it offers a seamless shopping experience with product browsing, features showcase, customer reviews, and a contact interface.

✨ Features
Responsive Design: Fully responsive layout optimized for desktop, tablet, and mobile screens.

Multi-Page Navigation:
Home: Hero section, core features, best-selling products, and newsletter subscription.
Products: Product catalog equipped with search bar filtering UI and direct "Buy Now" CTA buttons.
Contact: Interactive contact form and store location details.

Tailwind CSS Styling: Built using modern utility-first CSS classes for clean, scalable design.

Custom Branding: Styled under the signature Nova- project series.

🛠️ Tech Stack
Frontend: HTML5, Tailwind CSS
Icons & Assets: FontAwesome / Custom SVG icons
Version Control: Git & GitHub
